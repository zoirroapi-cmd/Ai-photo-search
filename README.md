# AI Life Memory (рабочее название)

Персональный AI-ассистент, который помогает ориентироваться в собственной цифровой жизни.

## Большая идея (Vision)

Цель проекта — сделать сервис, в который можно выгрузить разные части своей жизни (фото, заметки, календарь, позже — сообщения), и потом задавать ему вопросы на естественном языке:

- «Найди фото, где я летал в Таиланд»
- «Покажи, когда я последний раз был у врача»
- «Найди мои заметки про отпуск»
- «Liza в галерее» (поиск по человеку + контексту)

Сервис должен понимать смысл, людей, места и время.

## Текущий статус

Сейчас реализован **первый модуль** — семантический поиск по фотографиям с распознаванием лиц.

### Что уже работает

- Семантический поиск по смыслу фотографий («cat», «праздник», «дерево»)
- Поиск по конкретному человеку на основе образцов лиц
- Комбинированные запросы («liza в галерее»)
- Поддержка русского языка (автоперевод запроса)
- Поддержка HEIC (фото с iPhone)
- Веб-интерфейс с превью
- Сохранение индекса на диск (повторный запуск быстрый)
- Полностью локальная работа (кроме перевода запроса и первой загрузки модели)

### Стек первого модуля

- `open_clip_torch` (ViT-B-32) — семантический поиск
- `face_recognition` — распознавание лиц
- `FastAPI` + `uvicorn` — веб-интерфейс
- `pillow-heif` — поддержка HEIC
- PyTorch + MPS (Apple Silicon)

## Планы по развитию

| Модуль | Статус | Описание |
|--------|--------|---------|
| Фото + лица | ✅ Готово | Семантический поиск + поиск по людям |
| Заметки | ⬜ В планах | Поиск по личным заметкам |
| Календарь | ⬜ В планах | Вопросы по событиям и частоте («сколько раз был у врача») |
| Мессенджеры | ⬜ Дальняя перспектива | Поиск по сообщениям |
| Единый интерфейс | ⬜ В планах | Один поисковый запрос по всем источникам |

## Почему проект разделён на модули

Полная реализация «помощника по всей жизни» — большая и сложная задача. Поэтому я развиваю проект поэтапно: сначала закрываю один вертикальный срез (фото), делаю его стабильным, и только потом добавляю следующие источники данных.

## Известные ограничения текущего модуля

- Распознавание лиц маленьких детей работает нестабильно
- Модель CLIP ViT-B-32 не всегда хорошо понимает сложный контекст
- Есть ограничения совместимости некоторых библиотек с новыми версиями Python
