# AI Photo Search

Локальный семантический поиск по фотографиям с распознаванием лиц.
Работает полностью офлайн (кроме перевода запросов и первой загрузки модели).

## Что умеет

- Семантический поиск по смыслу фото: "cat", "праздник", "дерево" — без тегов и подписей
- Поиск по конкретному человеку: "liza", "nika" — на основе образцов лиц
- Комбинированный запрос: "liza в галерее" — сначала фильтр по лицу, потом ранжирование по смыслу
- Поддержка русского языка (автоперевод запроса)
- Поддержка HEIC (фото с iPhone)
- Веб-интерфейс с превью фотографий
- Сохранение индекса на диск — повторный запуск мгновенный

## Стек

- `open_clip_torch` (ViT-B-32, openai pretrained) — семантический поиск
- `face_recognition` (dlib) — распознавание и сравнение лиц
- `scikit-learn` — кластеризация лиц (эксперимент, не используется в финальной версии)
- `deep-translator` — перевод RU → EN
- `FastAPI` + `uvicorn` — веб-интерфейс
- `pillow-heif` — поддержка HEIC
- PyTorch + MPS (Apple Silicon)

## Структура проекта
ai-memory/

├── photos/              # все фотографии

├── people/              # образцы лиц для распознавания (name_1.jpg, name_2.jpg...)

├── search.py            # CLI-версия поиска + создание индекса

├── app.py               # веб-версия (FastAPI)

├── faces.py             # поиск всех лиц на всех фото → faces.pkl

├── find_person.py       # поиск конкретного человека по образцам

├── cluster_faces.py     # кластеризация лиц (эксперимент)

├── index.pt             # сохранённый CLIP-индекс (создаётся автоматически)

└── faces.pkl            # сохранённые лица (создаётся автоматически)

## Установка

```bash
python -m venv .venv
source .venv/bin/activate

pip install open_clip_torch==2.20.0
pip install fastapi uvicorn python-multipart
pip install deep-translator
pip install pillow-heif
pip install face_recognition
```

## Запуск

### 1. Первый запуск — создание индекса

```bash
python search.py
```

Проиндексирует все фото в `photos/`, сохранит в `index.pt`.
При следующих запусках индекс просто загружается — быстро.

### 2. Поиск лиц (опционально, для поиска по имени)

Положи 3-5 фото каждого человека в `people/` с именем в названии:
people/liza_1.jpg

people/liza_2.jpg

people/nika_1.jpg

Затем:

```bash
python faces.py          # находит все лица на всех фото
python find_person.py    # проверка — кто на каких фото
```

### 3. Веб-интерфейс

```bash
uvicorn app:app --reload
```

Открыть `http://localhost:8000`

## Известные ограничения

- Python 3.14 + `huggingface_hub` несовместимы (нет модуля `cgi`) — используем `pretrained="openai"` вместо `laion2b`, грузится напрямую без huggingface
- Распознавание лиц детей младшего возраста ненадёжно (типичная проблема технологии, не только этого проекта)
- CLIP `ViT-B-32` не самая точная модель — при крупных лицах в кадре хуже различает фоновый контекст
